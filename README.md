# سنام — مقترحات الهوية البصرية

موقع عرض ثابت (HTML/CSS/JS بدون أدوات بناء) يعرض ثلاثة اتجاهات لهوية «سنام»:

- `/` الصفحة الرئيسية وملخص بحث السوق
- `/sadu/` الاتجاه A · سدو
- `/seen/` الاتجاه B · سين
- `/wasm/` الاتجاه C · وسم
- `/compare/` المقارنة

كل التطبيقات (التغليف، السيارة، الزي، التطبيق، السوشيال) مرسومة في `assets/kit.js` من ألوان وشعارات كل اتجاه في `assets/brands.js`.
